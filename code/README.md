# Bound Calculator

## Introduction

This is a program calculating a variety of bounds on the size of codes, including the Hamming bound, the Singleton bound, the Plotkin bound, and also showing known optimal bounds and their examples for some parameters.

## Usage

To run the program, simply execute `python code/bound_calc/main.py` in the terminal. The program will print out the bounds for specified parameters, and also show the known optimal bounds and their examples.

## Inputs
The program takes no inputs from the user. The parameters for the bounds are hardcoded in the `main.py` file, and can be modified as needed.

## Outputs
The program outputs the calculated bounds for the specified parameters, as well as the known optimal bounds and their examples. The output is printed to the terminal.
